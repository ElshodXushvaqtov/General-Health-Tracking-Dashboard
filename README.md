# 🏥 General Health Tracking Dashboard

## 📊 Overview

This project presents an interactive **Health Tracking Dashboard** built in Power BI using real-world data sourced from Uzbekistan’s open data platform. The dashboard enables users to explore and analyze key health-related indicators through clear and interactive visualizations.

The goal is to transform raw public data into meaningful insights that can support awareness and better decision-making in the context of health and lifestyle.

---

## 🎯 Objectives

* Analyze publicly available health-related data
* Identify trends and patterns across time and indicators
* Present insights through an intuitive and interactive dashboard
* Demonstrate data visualization and analytical skills using real datasets
